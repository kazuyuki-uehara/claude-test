# AI駆動アプリケーション - 認証機能

このドキュメントでは、AI駆動アプリケーションに実装された認証機能について説明します。

## 実装された機能

1. **ユーザー認証**
   - ユーザー登録
   - ログイン/ログアウト
   - JWT（JSON Web Token）による認証
   - セッション管理

2. **権限管理**
   - 一般ユーザー (user)
   - 管理者 (admin)

3. **管理者機能**
   - ユーザー一覧表示
   - ユーザー管理（権限変更、削除）

## セットアップ方法

1. **依存パッケージのインストール**

```bash
npm install
```

2. **管理者ユーザーの作成**

```bash
npm run create-admin
```

このコマンドで以下の管理者アカウントが作成されます：
- ユーザー名: admin
- パスワード: admin123

## 使用方法

### ユーザー登録

1. ホーム画面右上の「登録」ボタンをクリック
2. ユーザー名、パスワード、その他情報を入力
3. 「登録」ボタンをクリック

### ログイン

1. ホーム画面右上の「ログイン」ボタンをクリック
2. ユーザー名とパスワードを入力
3. 「ログイン」ボタンをクリック

### ログアウト

1. ログイン後、ホーム画面右上の「ログアウト」ボタンをクリック

### 管理者機能へのアクセス

1. 管理者ユーザーでログイン
2. ブラウザで `/admin` にアクセス（例: http://localhost:3000/admin）

## 技術詳細

### 使用技術

- Next.js（フロントエンド・バックエンド）
- SQLite（データベース）
- JWT（認証トークン）
- bcryptjs/crypto（パスワードハッシュ化）

### ファイル構成

```
lib/auth/
  ├── auth-controller.js - 認証コントローラー
  ├── auth-middleware.js - 認証ミドルウェア
  ├── db.js - データベース操作
  └── utils.js - ユーティリティ関数

app/api/auth/
  ├── login/ - ログインAPI
  ├── logout/ - ログアウトAPI
  ├── me/ - 現在のユーザー情報API
  └── register/ - ユーザー登録API

app/api/admin/
  └── users/ - 管理者用ユーザー管理API

app/
  ├── login/ - ログインページ
  ├── register/ - ユーザー登録ページ
  └── admin/ - 管理者ページ

scripts/
  └── create-admin-user.js - 管理者ユーザー作成スクリプト
```

### セキュリティ上の注意

- 本番環境では、JWT_SECRET を環境変数から取得するように変更してください
- パスワードの複雑さを要求するバリデーションを追加することを推奨します
- ユーザー登録時のメール確認機能を追加することを検討してください

## 認証の流れ

1. ユーザーがログインすると、JWTトークンがクッキーに保存されます
2. 保護されたルートにアクセスすると、ミドルウェアがトークンを検証します
3. トークンが無効またはない場合は、ログインページにリダイレクトします
4. 管理者機能にアクセスするには、ユーザーのロールが 'admin' である必要があります
